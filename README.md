# Traffic Light Controller Using Timer and Sensor

## Project Overview
This project implements two traffic light controller designs
using Verilog HDL and finite state machines (FSM).

1. Timer-Based Traffic Light Controller
2. Sensor-Based Traffic Light Controller

## Project Files

- sensor_controller.v
- sensor_controller_tb.v
- timer_controller.v
- timer_controller_tb.v

## Tools Used

- EDA Playground
- Verilog HDL
- Icarus Verilog
- EPWave

## Simulation

Both controller designs were compiled and simulated using
their respective testbench files.

The simulation waveforms were used to observe state transitions
and traffic light output changes.

## Conclusion

This project demonstrates the use of Verilog HDL, FSMs,
timer counters, sensor inputs and simulation waveforms
in traffic light controller design.
