# Traffic Light Controller Using Timer and Sensor

## Project Overview
This project implements a traffic light controller using
Verilog HDL and finite state machines (FSM).

It includes:
1. Timer-Based Traffic Light Controller
2. Sensor-Based Traffic Light Controller

## Project Files
- sensor_controller.v - Sensor-based controller design
- sensor_controller_tb.v - Sensor controller testbench
- timer_controller.v - Timer-based controller design
- timer_controller_tb.v - Timer controller testbench

## Tools Used
- EDA Playground
- Verilog HDL
- Icarus Verilog
- EPWave

## Simulation Results
Both controller designs were simulated using testbenches.
The waveforms show state transitions and traffic-light
output changes.

## Conclusion
The project demonstrates how finite state machines,
clock signals, timers, and sensor inputs can be used
to control traffic signals.
